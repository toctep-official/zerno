# Зерно — сайт кофейни

Одностраничный сайт кофейни-обжарочной: меню с вкладками, обжарка, зерно на продажу, команда, каппинги и мастер-классы с переключателем «разово / абонемент», отзывы, FAQ и онлайн-бронь столика.

Чистые HTML, CSS и JavaScript — без сборки и библиотек. Чтобы посмотреть, откройте `index.html` в браузере.
